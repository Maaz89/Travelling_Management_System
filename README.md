# Travel Management System

A web-based Travel Management System developed using PHP and MySQL that automates travel booking and management operations. The system allows users to register, log in, search available buses/routes, book tickets, and view booking details through an interactive interface. An admin panel is included for managing buses, schedules, routes, users, and bookings efficiently.

The project follows a full-stack development approach by integrating frontend design with backend processing and database management. It implements CRUD operations, session handling, authentication, and relational database concepts to ensure smooth system functionality.

## Features

* User Registration & Login Authentication
* Admin Dashboard
* Bus & Route Management
* Ticket Booking System
* Schedule & Seat Management
* Booking History
* Database Integration using MySQL
* Responsive User Interface

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap

## Purpose

The main objective of this project is to digitize and simplify transportation/travel booking processes by providing an efficient, secure, and user-friendly platform for both customers and administrators.
